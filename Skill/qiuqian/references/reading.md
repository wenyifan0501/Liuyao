# 关帝灵签解读方法

## 1. 三层分离

用户看到的回答必须能分清这三层：

| 层次 | 内容 | 要求 |
| --- | --- | --- |
| 原文 | 签题与四句签诗 | 逐字引用 `title`、`poem`，保留繁体，不改字 |
| 释义 | 诗句的白话意思 | 忠于字面与常见诗词意象，不扩写成故事 |
| 阐释 | 结合用户问题的理解 | 明确是"放到你这件事上看"，可以有判断，但不冒充原文 |

## 2. 释诗

- 先整体说这首诗写的是什么情景（例如登高、行舟、守待、春回），再逐句或两句一组解释关键意象。
- 常见意象可按通行诗词含义理解：云、月、春风、舟、桥、山、雨等。生僻词按字面谨慎解释，不确定时直说"此处有不同理解"。
- 录文存在异文时，按提供版本解释，不自行"校正"。

## 3. 联系问题

- 找出诗中与用户所问最贴合的一两句作为主轴，不必每句都硬套到现实。
- 把诗中的处境映射到用户的具体情况，至少考虑两种映射，选择与用户背景更吻合的一种。
- 诗意与用户问题明显不相干时，坦率说明这支签更像在提示某种态度或时机，而不是牵强附会。

## 4. 等级处理

| 等级 | 表达方式 |
| --- | --- |
| 上上、大吉、上吉 | 说明基调顺，同时指出诗中提示的前提或需要守住的条件，避免让用户放松必要的努力 |
| 中吉、下吉、上平、中平、下平 | 说明吉凶参半或需待时，重点讲清诗中指向的条件与转机 |
| 下下 | 语气平稳，不渲染灾祸；把它理解为"当前方式或时机不宜"，给出可调整的方向 |

等级只定整体基调。具体判断仍以诗意与用户处境的对应为准，不把"下下"说成必败，也不把"上上"说成必成。

## 5. 首轮输出

1. 签号与签题，完整引用四句原文。
2. 一句话给出这支签对用户所问之事的整体意思。
3. 白话释诗，并标出与问题最相关的句子。
4. 结合用户处境的阐释与一条具体可执行的建议。
5. 如有值得深挖的诗句暗示，可用一句话点出供用户选择。

## 6. 追问

- 沿用同一支签，不重抽，不建议"再求一签看看"。
- 针对追问，回到具体诗句重新解读，而不是重复首轮全文。
- 新问题与原问事无关时，建议另开一次问事。
