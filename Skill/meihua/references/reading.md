# 梅花易数解读方法

## 1. 结构

| 要素 | 含义 | 来源 |
| --- | --- | --- |
| 体卦 | 问事者自身、己方立场与可控资源 | `body` |
| 用卦 | 所问之事、对方、外部环境 | `use`，即动爻所在经卦 |
| 本卦 | 事情当前的格局与起点 | `primary` |
| 互卦 | 事情发展中的过程、内部牵动与隐含因素 | `mutual` |
| 变卦 | 动爻变化后的走向与可能落点 | `changed` |
| 动爻 | 变化发生的位置；1–3 在下卦，4–6 在上卦 | `moving` |

## 2. 体用生克（主轴）

`relation` 为程序给出的五种关系之一，按以下倾向理解：

| 关系 | 传统倾向 | 现实化表达 |
| --- | --- | --- |
| 用生体 | 较顺，外部助力 | 环境或对方在给你资源、机会或回应，重点在接得住 |
| 体用比和 | 较顺，同气相求 | 双方立场接近，推进阻力小，但也可能缺少外部推力 |
| 体克用 | 可成而费力 | 主动权在你，但要付出控制、争取或消耗 |
| 体生用 | 有耗泄 | 你在持续付出，回报慢或被消耗，需要评估投入是否值得 |
| 用克体 | 阻力较大 | 外部压力、条件或对方对你构成约束，宜先护住自身底线 |

这些是倾向而非判决。至少用本卦或变卦的象意去印证或修正它：例如"体克用"但变卦象意趋向阻滞，应说明"可争取但过程不顺"，而不是简单报吉。

## 3. 旺衰与互变生克（程序事实）

`computedFacts.trigrams` 给出每个经卦的 `relation`（对体卦）与 `state`（月令旺衰）：

| state | 含义 | 用法 |
| --- | --- | --- |
| 旺 | 当令，力量最足 | 体旺：自身有底气；用旺：外部之事势头强 |
| 相 | 得令所生，次强 | 力量在上升 |
| 休 | 生令而泄，力量退下 | 已过最好时机或精力分散 |
| 囚 | 克令受制，力量受困 | 想动但受环境牵制 |
| 死 | 被令所克，力量最弱 | 当前几乎无力，需等待时令转换 |

- 权衡顺序：先看体用生克定方向，再用体与用的旺衰定力度。例如"用克体"但用卦休囚、体卦旺相，阻力虽在却不足为患；"用生体"但用卦死，助力有名无实。
- 互卦两卦对体卦的生克说明过程中的助力或消耗；变卦对体卦的生克说明走向的落点。生体为助，克体为阻，比和为同道，体生之为付出，体克之为可控但费力。
- 引用这些关系时直接采用 `computedFacts` 的结论，不自行推算五行方向。
- 没有旺衰（`monthBranch` 为空）时，只用生克与象意，不提旺衰。

## 4. 三卦叙事

- 本卦：先用卦名与上下经卦的取象，讲清"现在是什么局面"。
- 互卦：讲"推进时会碰到什么"，适合解释用户隐约感到的中间环节或内部牵动。
- 变卦：讲"若照现在的方式走下去，会转向什么"，并点出动爻在上卦还是下卦（变化起于外部还是自身一侧）。
- 卦名可借用《周易》通行含义帮助理解，但不得编造爻辞原文；引用卦辞时只说大意，不伪造出处。

## 5. 取象映射

- 用 [trigrams.md](trigrams.md) 的类象把体卦、用卦映射到现实中的人、事、物或状态，至少考虑两种映射，选择与用户背景最吻合的一种。
- 类象是比喻工具，不得据此断定具体人物身份、疾病或他人隐私。

## 6. 首轮输出

- 开头一句话给出主判断：结合体用生克、旺衰力度与变卦落点说清倾向。
- 正文围绕中心命题展开：体用与旺衰 → 本卦处境 → 互卦过程 → 变卦走向。复杂问题可展开，简单问题不凑长。
- 结尾给一条与用户处境相关的具体建议；若有值得深挖的暗线（例如互卦揭示的中间环节），用一句话点出，供用户选择是否继续。
- 不展示字段名，不罗列 JSON。

## 7. 追问

- 沿用同一组本、互、变卦与体用，不重新取数。
- 围绕用户新问题重新映射体用（例如从"整件事"细化到"与某人的沟通"），说明哪部分判断因此更新。
- 新问题与原问事无关时，建议另开一次问事。
