# 卦义资料

`classics.json` 收录《周易》六十四卦卦辞、384 条爻辞，以及乾、坤的用九、用六；按文王卦序编号，与排盘引擎按编号关联。经文保留维基文库底本文字，不统一简繁或更改异体字；仅去除网页标记，并将爻位名称后的分隔标点统一为冒号。

底本：维基文库《周易》，https://zh.wikisource.org/wiki/周易 ，采集日期 2026-09-10。每条记录保留具体篇章链接。仅提取古代经文，不引入现代译文、页面介绍、彖传或象传。古代经文本身属于公有领域；维基文库页面所声明的其他适用条款见 https://zh.wikisource.org/wiki/Wikisource:版权信息 。导入脚本保留于 `scripts/import-hexagram-reference.mjs`，手动运行才会访问来源；网站运行时不请求维基文库。

`readings.ts` 是本站整理的简要白话导读，以便理解经文意象，并非逐字翻译或唯一解释。它独立于咨询问题，也不参与六爻取用、旺衰或断卦。古代家庭、婚姻与刑罚等意象按历史语境阅读，不作为现代行为规范。

校订：同人九四“弗克，攻吉”改为“弗克攻，吉”；剥卦辞“不利。有攸往”改为“不利有攸往”；复初九“不復遠，无袛悔”改为“不遠復，无祗悔”。中国哲学书电子化计划的对读链接保存在 `collations.ts`，并显示在对应卦的来源区。除此之外的异体字与断句沿用底本。本次做了覆盖与爻位校验、通读和以上校订，不宣称完成学术版本校勘。

维护要求：每卦一条主题、一条卦辞导读及六条爻辞导读，爻位自下而上。用九、用六仅作补充资料，不作第七爻，也不自动触发断卦。来源更新后运行 `tests/hexagram-reference.test.ts`，检查覆盖率、爻序、阴阳和解析残留，并人工复核文字变化。
