# 网页 AI 接入

网页复用当前 CLI 的 `frameConsultationQuestion`、`runDirectInterpretation` 和 `runDirectFollowUp`，以及 `loadLiuyaoSkillBundle`。未改写 Skill、措辞或排盘。沿用 `.env` 中 DeepSeek 密钥、模型、思考配置；问事澄清使用 low 强度，正文使用配置的强度。

## 使用

在 `.env` 配置已有 `DEEPSEEK_API_KEY` 后重启 `npm run web:local`。启动不会调用模型。新问事可以先点击“确认问题”，按需要补充背景，再起卦；已有卦盘点击“开始 AI 解读”，生成后在同一页继续追问。澄清非强制，沿用原问题起卦也可进行；已起卦咨询不会再次修改问题背景。

首轮解读预占 1 次试用权益，完成后结算，失败退还；追问使用该账号获赠的每卦追问上限。起卦前澄清不扣咨询次数，但必须有剩余试用额度，且每卦最多 3 次调用（包括失败）。免费追问耗尽后提示付费尚未开放，不继续调用供应商。以上预占与上限仅在 `WEB_QUOTA_ENFORCED=true` 时生效，默认关闭，见下节。

## 数据与运行

- 迁移 `002-ai-runs.sql` 新增持久任务和每日预算表。标准 PostgreSQL 模式先执行 `npm run db:migrate`；本地模式自动迁移。
- API 用事务保存任务、预占额度和预算，返回 202；同一咨询最多一个活动任务。幂等键重发不重复调用。
- 当前是数据库任务表驱动的轻量 Worker，与 API 同进程启动；`FOR UPDATE SKIP LOCKED` 与事务锁控制领取，跨进程全局最多两个运行任务。未引入 pg-boss/Redis，以兼容本机 PGlite；后续高可用部署再拆独立 Worker。
- 网页每 2 秒读取生成中的正文快照，空闲时每 8 秒更新；目前采用轮询而非 SSE。后台每约 600ms 最多持久化一次正文增量，不传送 reasoning_content。
- 刷新、关闭浏览器不终止生成。排队任务重启后继续领取；运行中断的任务 5 分钟到期后标记失败并退还试用权益，禁止自动重放模型调用。用户显式重试才建立新任务。
- Gateway 单次超时 180 秒，不进行自动调用重试。失败的临时文本不进入历史回答和追问上下文。后续上下文只使用成功回答，始终保留同一卦盘和首轮解读。
- 保存模型名、Skill 内容哈希、用量和审查结果；队列中的模型/Skill 与当前运行配置不一致时，任务失败并要求显式重试，避免错误归因。
- 所有 AI 状态和提交接口都检查咨询归属。Cookie、密钥和供应商内部错误不发送给前端。Markdown 默认禁用原始 HTML。

## 额度开关

当前默认**放开额度**，供内测阶段自由使用：免费咨询次数、每卦追问上限、每日调用数和每日 token 预算都不再拦截入队，也不预占或扣减试用权益。页面按「咨询次数不限」「追问次数不限」展示。

要恢复限制（准备大批量开放时），在 `.env` 增加 `WEB_QUOTA_ENFORCED=true` 后重启即可，无需迁移或改代码：

```dotenv
WEB_QUOTA_ENFORCED=true
WEB_AI_USER_DAILY_CALLS=12
WEB_AI_DAILY_TOKEN_BUDGET=2400000
```

账本表（`trial_accounts`、`trial_reservations`、`entitlement_ledger`、`ai_daily_budget`）与邀请码授予的额度一直保留，放开期间只是不再读写检查，重新开启后历史数据仍可用于结算与审计。每卦澄清最多 3 次属于交互护栏，不受该开关影响。

## 成本边界

`WEB_AI_ENABLED=false` 可关闭新 AI 服务；`WEB_AI_USER_DAILY_CALLS` 默认 12，包含澄清、首轮、追问和失败。`WEB_AI_DAILY_TOKEN_BUDGET` 默认 2,400,000。这两项仅在 `WEB_QUOTA_ENFORCED=true` 时生效。

每个任务预留 120,000 token 的保守预算：输入最多 96 KB UTF-8（含预留消息开销），输出最多 24,000 token。正文仍沿用现有流程的 24,000/16,000 上限，澄清使用 Gateway 的结构化上限。预算用于限制调用，并非精确金额报价；实际 token 用量独立记录。失败也保留预算占用，防止退还用户权益后无限重试。预算按 UTC 日切换，达到上限不再入队；跨日排队任务在开始前重新预留当天预算，当天不足则继续等待。输入超出预算时失败而非默默截掉卦盘或首轮上下文。

当前免费内测形态尚无支付、独立收费额度池、短信/设备风控、跨区域高可用或精确金额账单。上限可按真实试用成本调节。数据库失联或应用长时间暂停时，实际状态与页面刷新有延迟；正式公开前仍需真实 PostgreSQL 多连接和部署故障测试。

## 测试

`tests/web-ai.test.ts` 使用实际 PostgreSQL SQL（PGlite）与测试处理器验证：幂等入队、一次扣退、失败不自动重放、恢复中断、固定卦盘追问、额度和预算上限、跨账号隔离、异步 API。测试不消耗真实模型费用。真实模型需另以测试卦例验证。
