# 书斋主界面

`npm run web:local` 启动后访问 `http://localhost:5173/`。`#/study` 保留兼容；原有 `#/consultations/:id` 在书斋中打开对应咨询。

## 操作与数据

- 原 App 页面已移除；书斋接入登录、邀请码注册、新建问事、问事簿、完整卦盘、AI 问题确认、解读和追问。
- 在纸张上创建问事后，按住龟甲来回拖动。龟甲位移与倾斜跟随鼠标或触摸指针；达到距离及换向条件后，松手倒币。轻点、静止长按或单向拖动不会起卦。
- 底部操作区支持相同拖动，另支持左右方向键来回摇动、Enter / 空格松手、Escape 取消。失焦、页面隐藏和 pointercancel 会取消手持状态；第二个指针不会加入当前手势。
- 铜钱出壳后用 Rapier 模拟碰撞，停稳并平放后读取朝向得到 6/7/8/9。12 秒未落定不记爻，允许重试。
- 六爻按初爻到上爻提交服务端 `/cast`，使用现有 `three_coins` 类型。失败保留原值供原请求重试；保存后不允许重摇。既有服务端鉴权、不可变卦盘与额度规则不变。
- 未提交的已落定爻保存在本标签页 sessionStorage，按用户和咨询隔离；刷新恢复，卦盘保存后清除。只存爻值，不存问题或对话。关闭整个标签页后可能丢失未保存进度。
- 也可录入真实铜钱结果；手动录入与桌面摇卦不混用。
- 对话蒙版使用真实 AiPanel，无演示消息。只在用户主动点击生成时调用 AI；打开、查看历史或排盘不调用模型。

## 技术边界

模型和纹理由本地程序生成，无外部资产请求。龟甲内部尚未做碰撞模拟；铜钱用薄圆柱碰撞体，外观带方孔。浏览器物理结果尚未做概率分布校验，此交互仍需在真实移动设备上检查性能与手感。3D 包只在首次加载书斋时下载，压缩后约 1.1 MB。

## 检查

新增手势测试覆盖轻点、单向拖动、抖动、换向、最小时长、多指干扰、纵向摇动和重复松手。前端构建与 AI 后端回归测试通过。浏览器使用独立合成问事测试，不发送真实 AI 请求。
