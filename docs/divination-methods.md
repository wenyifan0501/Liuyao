# 书斋新增三种问事方式

## 入口与数据

在信笺底部选择六爻、梅花易数、求签或掷筊，落印后对应器具出现。旧记录默认六爻。
`004-divination-methods.sql` 为咨询增加 method 和 oracle 字段；旧 chart 原样保留。
结果由服务器计算或使用 node:crypto.randomInt 抽取，事务锁保证每次问事只有一份固定结果。
收藏、删除、额度与追问沿用现有账号逻辑。一次首轮 AI 解读消耗一次额度，起卦不消耗。
三种新增方式不填写伪造的六爻 chart，AI 从 oracle 字段读取结果并使用独立提示规则。

## 规则版本 v1

- 梅花：三个正整数，第一数上卦、第二数下卦、第三数动爻；分别模八、八、六，余零作八、八、六。先天卦序乾兑离震巽坎艮坤。动爻所在经卦为用，另一为体。互卦由二三四、三四五爻组成。这是本产品固定的现代三数输入取法，不声称是所有梅花流派的统一起法。基本卦序与互卦可参照《梅花易数》卷一：https://zh.wikisource.org/wiki/梅花易數/卷一 。
- 求签：关帝百签，100签等概率。独立抽签，不自动声称通过某座庙宇的掷筊验签流程。
- 掷筊：两块独立等概率取上表面；一平一凸为圣筊、两平为笑筊、两凸为阴筊。此为数字模拟，不是测量真实木筊的概率。一次问事一次结果，不自动重掷直到圣筊。

## 签诗来源

仅收录古典七言四句原文，保留繁体；不抓取现代解说或占验。
来源：维基文库《关圣帝君灵签》各签子页面，逐签链接存储在 guandi.json。
https://zh.wikisource.org/wiki/關聖帝君靈籤
该古典作品公有领域；各页录文存在异文，按下载版本保存。抓取日期：2026-09-22。
导入脚本：scripts/import-oracle-poems.py（维护时需 Python beautifulsoup4）；网页运行不访问外部签诗站点。
导入校验：编号1–100、每签四句、每句七字。仅剔除括号字注，不改写诗句。

## 解读 Skill 与输出对齐

每种方式有独立 Skill，与六爻 `Skill/liuyao/` 平级：

- `Skill/meihua/`：体用生克定方向、月令旺衰定力度，本、互、变三卦叙事，附八卦类象表；不用六爻纳甲体系，不编造精确应期。
- `Skill/qiuqian/`：原文、释义、阐释三层分离，按签等级调整语气；不编造解曰与典故，不声称经过掷筊验签。
- `Skill/jiaobei/`：三种筊象的传统含义与问题层次对应，首轮约 300–500 字；不鼓励重掷。
- `Skill/shared/oracle-reading.md`：与六爻 direct-reading 同构的内部推演、表达、留口与追问规则。
- `Skill/shared/oracle-safety.md`：固定结果、表达与安全边界。

运行时（`src/divination/interpretation.ts`）与六爻直断同构：首轮 `<consultation>`、追问 `<immutable_consultation>` + 最近 20 条对话 + `<current_question>`，token 上限首轮 24000、追问 16000，要求每轮追问至少产生一项新增分析。梅花额外附 `computedFacts`，并对输出做五行方向审计。起卦前的问题确认按方式区分：梅花确认体用所指，求签确认所问事项，掷筊要求收窄为单一是非问。

根目录可用 `SKILL_ROOT` 覆盖（默认 `Skill`），六爻仍可用 `LIUYAO_SKILL_PATH` 单独指定。各 Skill 的 `evals/evals.json` 为行为评测用例。

## 梅花事实账本

起卦时服务端按咨询时区记录 `calendar`（起卦时刻与月建，交节以精确节气时刻为界），`meihuaFacts.ts` 计算体、用、互下、互上、变五个经卦的五行、对体卦生克，以及按月建五行的旺相休囚死（当令旺、令生相、生令休、克令囚、令克死）。结果写入 `oracle.analysis`；旧记录没有起卦时间时，只给生克，不论旺衰。

## 界面

| 方式 | 桌面器具与动作 | 结果呈现 | 对谈 |
| --- | --- | --- | --- |
| 求签 | 朱漆「靈籤」签筒；按住左右摇，签筒随手倾斜、签枝颤动，摇够后一枝签滑出落在布上，签面写签号 | 竖排签纸：签号、四句签诗、签等朱印 | 朱红主色、「籤」水印 |
| 掷筊 | 一对月牙木筊（凸面朱漆、平面木纹）；按住合筊默念，松手抛起翻转，按服务器结果落定 | 筊面图示、筊名、三种筊象对照 | 赭橙主色、「筊」水印 |
| 梅花 | 先天八卦盘与梅枝；点击报三数，盘上依次点亮上下卦，六爻爻条自下而上落在盘前，动爻朱红 | 本互变三卦标体用、体用关系、五卦事实表；卦义页可读本、互、变三卦经文 | 梅红主色、「梅」水印 |

动画只表现过程，结果始终由服务器决定；结果未返回时器具停在半空或持续摇动，失败则回到静止。

## 交互和验证边界

签筒支持按住横向摇动，键盘左右方向键摇动、Enter/空格直接求签；木筊按住默念后松手抛出，键盘按住 Enter/空格后松开；梅花点击器具报数。
新器具采用程序建模和展示动画，结果取自服务器，动画不决定抽签或筊面概率。
AI 仍通过现有后台队列执行；自动化用假模型验证上下文、扣额和追问，未调用付费模型。
生产升级前执行 npm run db:migrate，并重启后端。Vercel 静态预览仍需要独立后端才可保存及解读。
